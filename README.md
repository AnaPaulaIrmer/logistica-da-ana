# Logística da Ana

Sistema web de gerenciamento logístico desenvolvido para a disciplina **Fundamentos de Programação para Internet**, da UNIPAR EAD.

## Sobre o projeto

O sistema permite gerenciar produtos, endereços, transportadores e fretes, facilitando a organização das informações logísticas.

## Funcionalidades

- Cadastro, edição e exclusão de produtos.
- Cadastro, edição e exclusão de endereços.
- Cadastro, edição e exclusão de transportadores.
- Cadastro, edição e exclusão de fretes.
- Associação de vários produtos a um frete.
- Consulta e geração de relatórios de fretes por data.

## Tecnologias utilizadas

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Ambiente de desenvolvimento

Projeto desenvolvido e testado utilizando XAMPP.

## Autoria

Projeto acadêmico desenvolvido para a UNIPAR EAD.
